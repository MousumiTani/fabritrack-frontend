## Project Overview

The **Garments Order & Production Tracker System** is a **web-based platform** built to streamline production management for small and medium-sized garment factories. The system provides a centralized interface for managing **orders, production stages, inventory, and delivery timelines**, helping factories improve efficiency, reduce errors, and ensure timely deliveries.

It is developed using the **MERN stack** (MongoDB, Express, React, Node.js) and includes **JWT authentication** and middleware for role-based access control.

---

## Features

### User Roles & Access

- **Admin**
  - Full control over the system
  - Can manage users, products, orders, and production workflow
- **Manager**
  - Can add and manage products
  - Track production stages and inventory
- **Buyer**
  - Can browse products
  - Place and track orders

### Core Functionalities

- User authentication and role-based access
- Buyer dashboard: place orders, view order history
- Manager dashboard: manage products, track production stages
- Admin dashboard: manage all users, products, and orders
- JWT-based secure authentication
- Middleware for route protection
- Responsive UI using React and Tailwind CSS
- Real-time order and production tracking

---

## Tech Stack

- **Frontend:** React, Tailwind CSS, React Router, Axios
- **Backend:** Node.js, Express.js, JWT authentication, Middleware
- **Database:** MongoDB
- **Authentication & Authorization:** JWT with role-based access
- **Other:** react-icons, sweetalert2, react-spinners
